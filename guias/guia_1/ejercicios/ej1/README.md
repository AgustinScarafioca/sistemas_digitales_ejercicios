# Ejercicio 1 — Identidades booleanas

Implementar las cinco igualdades de la consigna y comparar, para cada una,
el valor del lado izquierdo con el del lado derecho. La interfaz de trabajo
está en `guia_1_ej1.sv`; el testbench recorre las ocho combinaciones de
`x`, `y` y `z`.

```sh
make sim
make wave
make clean
```

El módulo superior para HDL Studio es `guia1_ej1`. Agregar el archivo de
diseño y excluir `guia_1_ej1_tb.sv`.
