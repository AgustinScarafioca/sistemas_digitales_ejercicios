# Guía 2 — Ejercicio 3

Comparar el latch D transparente con un flip-flop D disparado por flanco usando el cronograma de la consigna. Ambos módulos incluyen reset asíncrono para iniciar Q en 0 como pide el ejercicio.

## Archivos

- guia_2_ej3.sv: módulos latch_d y flipflop_d.
- guia_2_ej3_tb.sv: testbench que recorre los eventos de 0 a 20 ns y verifica ambas salidas.
- respuestas_teoricas.md: desarrollo teórico.

## Simulación

Desde esta carpeta, ejecutar make sim. También se puede usar make wave para generar y abrir la traza VCD.
