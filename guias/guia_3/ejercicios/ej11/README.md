# Guía 3 — Ejercicio 11

Sumador combinacional de 8 bits con carry, overflow y extensiones con y sin signo.

## Archivos

- `respuestas_teoricas.md`: hoja de trabajo con los requerimientos del punto.
- `guia_3_ej11.sv`: módulo combinacional inicial.
- `guia_3_ej11_tb.sv`: testbench autocontrolado inicial.
- `Makefile`: simulación Verilator.

## Simulación

Desde esta carpeta: `make sim`. Desde la raíz: `make sim GUIA=guia_3 EJ=ej11`. El testbench marca los casos pendientes con `TODO` hasta completar el diseño y las expectativas.
